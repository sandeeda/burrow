# Burrow 🐇

**Your own Google Drive with a brain, in one command.**

Burrow turns any folder on your PC into a private drive you can reach from your phone, anywhere — over [Tailscale](https://tailscale.com), with no open ports and nothing uploaded to the cloud.

```
burrow ~/Documents
→ ✅ Burrow is live at https://burrow.<tailnet>.ts.net
```

> 🚧 Early development. Not ready for use yet.
